# AI & Data Processing — StressStrike

## ภาพรวม
ระบบ AI และการประมวลผลข้อมูลในเกมทำสองสิ่ง:
1. **ระบบแนะนำโหมดเกม** (Game Mode Recommendation) — ใช้แบบประเมิน Brief-COPE (วิธีการรับมือความเครียด) เพื่อตัดสินใจว่าผู้เล่นควรเล่นโหมดไหน
2. **การปรับเสริมข้อความ** (Text Generation) — ใช้ Gemini LLM เพื่อเขียนข้อความสนับสนุนแต่ละคนแบบส่วนตัว

---

## 1. ระบบแนะนำโหมดเกม (Deterministic Recommendation Engine)

### วิธีการ
- **แหล่งข้อมูล:** Brief-COPE Inventory (Carver, 1997) — แบบประเมินทางจิตวิทยาที่ได้รับการตรวจสอบอย่างเป็นทางการ
- **ขั้นตอน:**
  1. ผู้เล่นตอบคำถาม 28 ข้อเกี่ยวกับวิธีการรับมือความเครียด
  2. ระบบคำนวณคะแนนในหมวดหมู่ 3 กลุ่ม:
     - **Approach Coping** (เผชิญหน้า) → แนะนำ **Boxing**
     - **Avoidant Coping** (หลีกเลี่ยง) → แนะนำ **Yoga/Meditation**
     - **Context-Dependent Coping** → แนะนำ **Rage Room** หรือ **Yoga** ตามสถานการณ์
  3. เลือกโหมดเกมที่ตรงกับลักษณะการรับมือของผู้เล่น

### เหตุผลในการออกแบบ
- **ไม่ใช่ Machine Learning:** เป็นตารางค้นหา (lookup table) ที่กำหนดไว้อย่างแน่นอน
- **ปลอดภัย:** ไม่มีการคาดการณ์จิตใจ หรือการวินิจฉัยทางการแพทย์
- **โปร่งใส:** คณะกรรมการและผู้เล่นเข้าใจได้ว่ามันใช้หลักจิตวิทยาใด
- **ขยายได้:** ใช้เครื่องมือที่มีการศึกษาวิจัยมากมายแล้ว (Brief-COPE)

## 2. การปรับเสริมข้อความ (Text Personalization with Gemini LLM)

### โมเดล
- **ชื่อ:** Google Gemini 3.5 Flash Lite
- **ที่ตั้ง:** Google's Generative Language API (ไม่เก็บข้อมูลผู้เล่นในสหรัฐฯ)
- **หน้าที่:** เขียนประโยคสนับสนุนแบบส่วนตัวสำหรับแต่ละคน

### สิ่งที่ Gemini ทำ
1. **ข้อความ Intro ของสำรวจ**
   - อ่านประวัติของผู้เล่น ("คุณเคยมาที่นี่มาก่อน?")
   - เขียนประโยค 1 ข้อ ต้อนรับแบบส่วนตัว

2. **ข้อความตรงกลาง (Halfway Text)**
   - ให้กำลังใจผู้เล่นขณะตอบแบบประเมิน
   - อย่าเปิดเผยว่าแนะนำโหมดไหน

3. **เหตุผลผลลัพธ์ (Result Reason)**
   - อธิบายว่าทำไมระบบจึงแนะนำโหมดนี้
   - อ้างอิงจากวิธีการรับมือที่ระบบตรวจพบ

### ข้อจำกัด
- **ไม่เลือกโหมด:** Gemini ไม่ตัดสินใจว่าเล่นโหมดไหน — ระบบ Brief-COPE เป็นผู้ตัดสินใจ
- **ไม่เก็บข้อมูล:** ข้อความที่ Gemini สร้างเก็บไว้ในเครื่องเฉพาะ ไม่อัปโหลดไปยังคลาวด์
- **ไม่วินิจฉัย:** ระบบแม่แบบ (prompt) บังคับให้ Gemini ไม่ให้คำแนะนำทางการแพทย์

### ตัวอย่างผลลัพธ์
```
Input:  "I've been staying active and facing my problems head-on"
Mode Decided: Boxing (จากคะแนน Brief-COPE)
Gemini Output: "Channel your drive and face challenges head-on by stepping into the ring with boxing."
```

## 3. การจัดเก็บข้อมูล (Data Collection)

### ข้อมูลที่เก็บในเครื่อง (LocalStorage)
```json
{
  "timestamp": 1725811262,
  "mode": "Boxing",
  "dominantCopingStyle": "Approach",
  "skipped": false
}
```
- **ที่ตั้ง:** `C:\Users\User\AppData\LocalLow\DefaultCompany\StressStrikegame`
- **จำนวน:** 1 บันทึก (อัปเดตทุกครั้งที่ผู้เล่นสำรวจ)

### ข้อมูลที่เพิ่มเติม (ถ้าเปิดใช้ Cloud Sync)
หากผู้เล่นยินยอม อนุญาตให้ระบบอัปโหลด:
- `SessionRecord`: โหมด, ระยะเวลา, คะแนน, แคลอรี่, HR ก่อน/หลังเล่น
- `SurveyRecord`: ผลลัพธ์ Brief-COPE, โหมดที่แนะนำ, ข้อความที่ Gemini สร้าง

### เมตริกที่สามารถวิเคราะห์
- เปรียบเทียบ HR ก่อน/หลัง แยกตามโหมด
- อัตราการแนะนำแต่ละโหมด
- ผู้เล่นที่กลับมาเล่นซ้ำ
- ความสัมพันธ์ระหว่างสไตล์การรับมือและการเลือกโหมด

## 4. หลักการด้านนิเวศวิทยา (Privacy & Ethics)

| เรื่อง | นโยบาย |
|---|---|
| **ข้อมูลส่วนบุคคล** | ไม่มีการเก็บชื่อ อีเมล หรือบัญชีผู้ใช้ — ใช้ ID แบบสุ่มต่อเครื่องเท่านั้น |
| **Cloud Sync** | ต้องได้รับอนุญาตอย่างชัดแจ้ง (Opt-in) — ค่าเริ่มต้นคือปิด |
| **ข้อความที่สร้าง** | เก็บไว้ในเครื่องแบบ JSON Lines (`coachbyte_history.jsonl`) เพื่อตรวจสอบ |
| **ไม่มีการวินิจฉัย** | Gemini ถูกบังคับด้วยแม่แบบให้ไม่ให้คำแนะนำทางการแพทย์ |

## 5. โปรแกรม Machine Learning ที่แท้จริง

**MediaPipe BlazePose (Full Variant)** ในโหมด Yoga:
- **อะไร:** Neural Network สำหรับตรวจจับท่าทาง ใช้ CPU
- **ผลลัพธ์:** 33 จุดสำคัญของร่างกาย อัตรา 30 FPS จากกล้องเว็บแคม
- **ใช้:** คำนวณมุมข้อต่อ ตรวจสอบว่าท่าทางถูกต้อง และให้คะแนน
- **เป็นหลัก:** นี่คือองค์ประกอบ ML ที่มีความสำคัญจริงในเกม
