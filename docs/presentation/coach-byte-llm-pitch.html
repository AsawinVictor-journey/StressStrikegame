Why it's the interesting part

Five decisions that make it an innovation, not a chatbot.

01 — Edge-first by architecture

The model lives with the player

Generation happens on-device via Ollama. Sensitive mental-health signals — coping answers, heart rate — never need a network to become a helpful sentence. Privacy isn't a policy here; it's the wiring.

02 — Latency-proof

The AI is a cosmetic layer

The deterministic recommendation renders first. Ollama's warmer phrasing only swaps in if it answers in time. The player is never staring at a spinner waiting on a token stream.

03 — Safe by construction

Guardrails compiled into the prompt

Every prompt hard-codes the persona and its limits — max 40 words, no diagnosis, no clinical language. The safety rules ship with the request, not as a hopeful afterthought.

04 — Data minimised

Only the verdict travels

If cloud sync is opted into, raw survey answers still stay on-device. Only the recommendation and winning subscale sync. The most sensitive data — item-level coping responses — never leaves.

05 — Tuned to real hardware

Numbers from the machine, not a guess

The 60s timeout is measured: ~37s cold-start to load the model, ~2s warm. An earlier 20s guess sat below the cold-start floor and failed silently — so it was raised on evidence.

06 — Auditable

Every line is logged locally

Generated text is appended to coachbyte_history.jsonl on the device. You can review exactly what the coach said over time and catch tone drift — without a telemetry pipeline.

The demo-day insurance policy

What happens when the AI isn't there.

The strongest claim in the build: if the model is missing, slow, or off, nobody watching can tell. Here's the ladder it falls down — gracefully.

STATE 01

Ollama running, model warm

Coach Byte answers in ~2s and the warm, human phrasing replaces the canned line.

STATE 02

Model cold

First request takes up to ~37s. The generous timeout absorbs it; the deterministic text is already on screen, so the wait is invisible.

STATE 03

Ollama not installed / stopped

The request fails, onError logs a single warning, and the flow continues untouched.

RESULT

The player sees a working game either way

Because the LLM is a layer on top of a deterministic system, "AI down" degrades to "slightly less warm wording" — never to a broken screen.

Private by default. Playable no matter what.

Coach Byte proves a stress-relief game can feel personal and spoken-to without shipping a single player's data to anyone's server.

Coach Byte's messages are game-flavour encouragement, not clinical advice. The Brief-COPE check-in suggests a play mode; it does not diagnose. That disclaimer is attached to every recommendation in the build.
